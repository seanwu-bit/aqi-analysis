# AQI 避難所風險分析專案

## 專案概述

本專案分析台灣避難所與空氣品質監測站的空間關聯，評估避難所在空氣污染事件中的風險等級，為應急決策提供支援。

## 工作流程 (Workflow)

### 階段 1: 數據載入與初步檢查
1. **載入原始數據**
   - 避難收容處所點位檔案 (5975 筆)
   - AQI 監測站數據 (85 個測站)

2. **初步數據檢查**
   - 檢查欄位完整性
   - 識別基本數據問題
   - 記錄原始狀態

### 階段 2: 數據清理與修正
1. **座標系統問題修正**
   - 零值座標檢測與修正 (814 筆)
   - 超出合理範圍座標修正
   - 經緯度交換問題處理

2. **區域座標異常修正**
   - 縣市邊界驗證 (812 筆異常)
   - 地理合理性檢查
   - 人工審核與修正

3. **台灣本島邊界處理**
   - 離島縣市排除 (金門、連江、澎湖)
   - 邊界定義與驗證
   - 926 筆邊界外記錄處理

4. **室內外屬性一致性修正**
   - 優先順序調整 (1139 筆不一致)
   - 原始欄位優先邏輯
   - 100% 一致性達成

### 階段 3: 空間分析與關聯
1. **空間疊圖分析**
   - Haversine 距離計算
   - 最近 AQI 測站搜尋
   - 空間分布驗證

2. **異常點位檢測**
   - 海洋中避難所檢測
   - 地理異常點識別
   - 17 筆異常點修正

### 階段 4: 風險標籤分析
1. **風險標籤算法實現**
   - High Risk: AQI > 100
   - Warning: AQI > 50 AND 室外設施
   - Medium Risk: AQI > 50 AND 室內設施
   - Low Risk: 其他情況

2. **模擬情境分析**
   - 鳳山測站 AQI=150 模擬
   - 73 所避難所影響評估
   - 空間合理性驗證

### 階段 5: 結果輸出與驗證
1. **分析結果生成**
   - CSV 格式詳細結果
   - 風險分布統計
   - 高風險避難所清單

2. **品質保證驗證**
   - 數據品質指標檢查
   - 邏輯一致性驗證
   - 模擬結果驗證

### 階段 6: 文檔與反思
1. **審核報告生成**
   - 整合所有分析結果
   - 問題與解決方案記錄
   - 技術挑戰與改進建議

2. **反思文檔撰寫**
   - 數據完整性反思
   - AI 協作經驗總結
   - 空間推理評估

## 主要功能

### 1. 數據清理與審核
- **座標異常檢測**: 零值、超出範圍、經緯度交換
- **區域座標驗證**: 縣市邊界合理性檢查
- **邊界處理**: 台灣本島邊界定義與離島排除
- **屬性一致性**: 室內外屬性邏輯一致性

### 2. 空間分析
- **Haversine 距離計算**: 精確的地理距離計算
- **最近測站搜尋**: 高效的空間關聯算法
- **空間疊圖**: 避難所與 AQI 測站分布可視化

### 3. 風險評估
- **四級風險分類**: High Risk, Medium Risk, Warning, Low Risk
- **多維度考量**: AQI 值與設施類型綜合評估
- **模擬功能**: 特定情境風險模擬

## 技術特點

### 算法實現
- **Haversine Formula**: 精確計算兩點間距離
- **空間索引**: 高效的最近測站搜尋
- **多層次風險分類**: 基於 AQI 值和設施類型

### 數據處理
- **自動化清理**: 異常座標檢測與修正
- **地理編碼**: OpenStreetMap API 整合
- **邊界驗證**: 台灣本島地理邊界檢查

## 技術挑戰與解決

### 主要挑戰
1. **數據品質問題**: 座標異常、區域不符、邊界外記錄
2. **AI 協作限制**: 台灣 CRS 幻覺、地理知識不足
3. **編碼問題**: UTF-8 與 CP950 編碼衝突
4. **大規模計算**: 5048 × 81 距離計算效率

### 解決方案
1. **本地化知識**: 加入台灣特定地理知識
2. **優先順序調整**: 原始欄位優先於推斷邏輯
3. **統一編碼**: 使用 UTF-8-sig 編碼
4. **向量化計算**: 提升大規模計算效率
