### 1.4 室內外屬性一致性问题

#### 發現問題
- **不一致記錄**: 1139 筆記錄 '室內'欄位為'是'但 'in_door' 卻標註'False'
- **原因**: 關鍵字判斷邏輯優先於原始 '室內' 欄位

#### 修正方式
- **優先順序調整**: 以原始 '室內' 欄位為最優先判斷
- **邏輯重構**: 
  1. 如果 '室內'=='是' → `in_door=True`
  2. 如果 '室內'=='否' → `in_door=False`
  3. 如果 '室內' 為空 → 使用關鍵字判斷

#### 修正結果
- **不一致記錄**: 0 筆（修正前 1139 筆）
